# Visual Notebook

Локальный визуальный блокнот для заметок, схем и связей между идеями. Работает на бесконечном холсте и не требует подключения к интернету.

> Скриншот интерфейса будет добавлен позже.

## Возможности

- Текстовые блоки, заметки, заголовки, чек-листы и группы.
- Перемещение и масштабирование холста, сетка и привязка к ней.
- Направленные и ненаправленные связи с подписями; доступны прямые и плавные линии с настройкой изгиба.
- Выбор цвета блоков и темы интерфейса.
- Интерфейс на русском, английском и украинском языках.
- Пошаговая инструкция при первом запуске.
- Локальные проекты `.vnote`, автосохранение и восстановление.
- Экспорт холста в PNG и PDF.
- Portable-сборка для Windows x64 и Linux-сборка в формате AppImage.

## Использование

Готовые сборки будут опубликованы в [Releases](https://github.com/artem-prime42/Visual-Notebook/releases). Пока их там нет, приложение можно собрать из исходников по инструкциям ниже. Установщик и отдельная установка Electron конечному пользователю не нужны.

Чтобы создать схему, выберите инструмент на панели и щёлкните по холсту. Перетаскивайте карточки мышью; для перемещения холста используйте среднюю кнопку мыши, для масштаба — колесо. Для связи включите инструмент «Связь» и перетащите линию от точки одного блока к другому.

### Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Новый проект | `Ctrl+N` |
| Открыть проект | `Ctrl+O` |
| Сохранить / сохранить как | `Ctrl+S` / `Ctrl+Shift+S` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Y` |
| Копировать / вставить | `Ctrl+C` / `Ctrl+V` |
| Дублировать / выделить всё | `Ctrl+D` / `Ctrl+A` |
| Удалить выбранное | `Delete` |
| Отменить текущее действие | `Escape` |

## Сборка из исходников

Для разработки необходимы Node.js и npm.

```bash
npm install
npm run dev
```

Сборка portable-приложения для Windows x64:

```bash
npm run dist:win
```

Результат: `dist/VisualNotebook.exe`.

Сборка AppImage для Linux x64 (в Linux или WSL):

```bash
npm run dist:linux
```

Скрипт создаёт `VisualNotebook-1.0.0.AppImage` в `dist-linux`. Для сборки нужен Linux-инструмент `mksquashfs`; при запуске скрипта в Windows он завершится с подсказкой использовать Linux или WSL.

## Данные и конфиденциальность

Проекты и настройки хранятся локально на устройстве пользователя. Приложение не использует облачное хранилище.
